## Purpose

03.12 mapped all **44** baseline risks to the controls that will treat them and named the phase that delivers each. This document does the same job from the other end: it takes the controls **Phase 04 actually built** and maps them back to the register, states what each achieves, and states what it does not.

It answers four questions and refuses to blur them.

| Question | Where |
|---|---|
| Which of the 44 risks does Phase 04 touch, and with what? | §3 |
| Which risks does Phase 04 **reduce**, and which does it merely **hold**? | §4 and §5 |
| Does every control Phase 04 built treat a risk the register contains? | §6 |
| Does the expected close position still reconcile to **0 High · 13 Moderate · 31 Low**? | §7 |

There is a fifth thing this document does, and it is the one that shapes everything else.

> **Nothing in the register moves in this document, and that is not a shortcoming.**
>
> The baseline register in 03.11 is dated **2026-07-15**. So is this phase. A traceability document published on the same day as the baseline it measures against cannot report movement without measuring something against itself. What it can report is what was **built**, what evidence each control has produced **so far**, and what still has to happen before a rating change is defensible — which for most of Phase 04's control set is **time**.

## 2. How to Read the Mapping

| Column | Meaning |
|---|---|
| **Baseline** | The rating in 03.11 at 2026-07-15 |
| **Phase 04 contribution** | The specific mechanisms built in this phase — named controls, not requirement numbers |
| **Standing** | **Primary** where Phase 04 delivers the control that moves the risk · **Contributory** where Phase 04 strengthens a risk whose decisive control is elsewhere · **Accommodation** where Phase 04 makes an unmeetable position manageable without reducing the exposure |
| **Still required** | What has to happen before the expected residual can be claimed |
| **Expected residual** | The Phase 09 close position predicted in 03.12 §6, restated unchanged so the two documents cannot diverge |

**Accommodation is not treatment.** 03.12 §5 established the distinction when the reverse test found NSC-EX-01's compensating position mapped as though it reduced R-15. Phase 04 inherits the rule and applies it to two entries.

## 4. What Actually Moved

Nothing, by construction — and the construction is worth defending rather than apologising for.

| Element | Position |
|---|---|
| Register baseline date | **2026-07-15** |
| This document's date | **2026-07-15** |
| Movements recorded here | **0** |
| Reason | A rating change requires evidence that the treated exposure has changed. On the day a control is published, the only evidence available is that the control exists. **The register does not score intentions** |
| Where movement is recorded | **Phase 09**, entry by entry, against this baseline, with the evidence for every reduction |
| What Phase 04 supplies to that | The control set in §1, the operating evidence in each document's coverage summary, and the prediction in §7 |

The alternative — reducing a rating because a control was implemented this quarter — is the failure mode ADR-0005 was written against, seen from the opposite direction. **ADR-0005 says a disproved assumption raises a rating even after complete remediation.** The mirror rule, which the programme applies here without needing a second decision record, is that **a control with no operating history does not lower one.**

## 6. Reverse Traceability — Controls That Treat No Risk

The forward map only tests the risks it started with. The reverse test asks the harder question, and 03.12 §5 set the rule the programme applies to the answer:

> **A control that treats no risk is either unnecessary, or the register is incomplete. "It is required by the standard" is not a third answer — a requirement exists because somebody identified a risk, and if Marketa's register cannot name it, Marketa has not understood the requirement.**

The reverse analysis was run across the Phase 04 control set in §1. **Six** controls mapped to no register entry on the first pass.

| Control with no initial mapping | Investigation | Resolution |
|---|---|---|
| **K-09** — the SSH certificate authority and its 8-hour issued certificates | Looked like operational hygiene for the administrative path | **Mapping error.** K-09 is a primary treating control for **R-18** and a contributory one for **R-27**: it makes SSH key sprawl structurally impossible, which is the persistence mechanism both entries depend on |
| **5.3.4 and 5.3.5** — anti-malware logging and tamper resistance | Appeared to be configuration detail inside Requirement 5 | **Mapping error.** 5.3.4 treats **R-28** — it is a log source whose silence must be alerted on — and 5.3.5 treats **R-20**, because the first action of a modern ransomware operator is to disable the agent |
| **6.5.6** — the test data and test account gate | Read as release hygiene | **Mapping error.** The 7 test accounts found in production were unattributed standing credentials on assessed components. That is **R-17**'s class exactly, and a contributory path into **R-12** |
| **4.2.2** — the end-user messaging position | Treated as a Requirement 4 formality in an estate that sends no PAN by message | **Mapping error.** It is a primary control for **R-07** and contributory for **R-22**, and the register was right that customer-initiated account data arrives by channels nobody designed for it |
| **BL-NET** — the network baseline | Appeared to be a seventh control set treating R-03 and R-04 | **Double count, removed.** BL-NET is **NSC-01 to NSC-14 restated as a build artefact** — the same control expressed in the form the assertion tooling consumes, deliberately, so the two cannot diverge. Recorded as a restatement rather than mapped as a Phase 04 treatment, because **counting one control twice inflates coverage exactly as reliably as omitting one deflates it** |
| **SCS-EX-01**'s compensating position — SNMPv2c read-only with a rotated string and a polling ACL | Treats no risk; it accommodates one | **Not a treatment.** The same conclusion 03.12 reached about NSC-EX-01, reached again about the same estate from a different requirement. Recorded as an accommodation of **R-15** in §3.3 |

| Reverse test | Result |
|---|---|
| Phase 04 control sets examined | The 6 baselines, SCS-01 to SCS-11, CA-1 to CA-6, K-01 to K-10, the Requirement 3, 4 and 5 control sets, 6.2.x and 6.3.x, CHG-1 to CHG-4, SIG-1 to SIG-10, 6.5.3 to 6.5.6, PFA-1 to PFA-6, and the 6.4.3 control set |
| Controls with no initial risk mapping | **6** |
| Resolved as mapping errors, corrected in §3 | **4** |
| Resolved as a double count and removed | **1** |
| Resolved as an accommodation rather than a treatment | **1** |
| Controls concluded to be **unnecessary** | **0** |
| Register entries added as a result | **0** — the register was complete; the map was not |

The recurrence of the SNMPv2c finding is the most instructive line in the table. **The same accommodation was mis-mapped as a treatment twice, by two different phases, against two different requirements**, which suggests the error is not carelessness but a gravitational pull: a compensating control looks like a treatment because it is written in the same language. The programme's answer is the register column in §3.3, which forces the distinction to be made in a place where it cannot be skipped.

| Limitation | Consequence |
|---|---|
| A mapping is not evidence of operation | This document proves a Phase 04 control is **assigned** to a risk and describes what it produced in 96 days. Phase 06 and Phase 08 prove it **ran** for a year |
| A prediction is not a result | The close position is a target published in July. Missing it is a legitimate outcome and Phase 09 will report it as one |
| Coverage is not sufficiency | Every risk Phase 04 touches has a named control. Whether the control is strong enough is a judgement the QSA, Ironwood and Rosa Delgado each test differently |
| The register bounds the analysis | The reverse test can find a control with no risk. **It cannot find a risk nobody thought of.** R-14 and R-31 are what it looks like when testing and discovery find one instead |
| Phase 04 cannot close what Phase 05 owns | Four of Phase 04's contributory mappings — R-12, R-17, R-18, R-21 — wait on Requirements 7, 8 and 9. Phase 04 built everything it can and says so rather than claiming the residual |
