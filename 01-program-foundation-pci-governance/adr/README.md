# Architecture Decision Records — Marketa Retail Group PCI DSS Program

ADRs are numbered continuously across this repository. **Phase 01 contributes 0001–0004.**

| ADR | Title | Status |
|---|---|---|
| [ADR-0001](ADR-0001-programme-operating-model.md) | Run PCI as a standing programme, not an annual project | Accepted |
| [ADR-0002](ADR-0002-aoc-signature-with-cfo.md) | Place the AOC signature with the CFO | Accepted |
| [ADR-0003](ADR-0003-qsa-asv-same-firm-independence.md) | Engage one firm as both QSA and ASV, with the independence position documented | Accepted |
| [ADR-0004](ADR-0004-no-not-tested-findings.md) | Permit no "Not Tested" finding in the ROC | Accepted |

## Convention
Each ADR records context, the decision, the rationale, the consequences, and the alternatives considered with the reason each was rejected. An ADR is written when a decision would otherwise be re-litigated later, or when a future reader would reasonably ask "why did they do it that way?"
